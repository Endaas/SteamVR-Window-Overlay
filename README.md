# SteamVR Window Overlay

A Windows application that displays a selected window or screen region as an overlay in SteamVR.

## Features

* Capture a selected application window or a screen region
* Display the captured image as a SteamVR overlay
* Position the overlay in VR space or attach it to a controller
* Adjust position, rotation, size, and opacity
* Configure capture margins

## Requirements

* Windows 10/11
* SteamVR
* A compatible VR headset
* .NET 8 SDK

## Build

1. Install the .NET 8 SDK.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run:

```bash
dotnet build -c Release
```
